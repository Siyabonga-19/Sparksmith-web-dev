# Sparksmith Electrical Services — WEDE5020 POE Part 2

## Project overview
This is the Part 2 visual-design and responsive version of the Sparksmith Electrical Services website developed from the Part 1 proposal.

## Pages
1. `index.html` — Home
2. `about.html` — About Us
3. `services.html` — Services
4. `products.html` — Products
5. `contact.html` — Contact & Enquiry

## Part 2 improvements
- Replaced the Part 1 inline styling with one external stylesheet: `styles.css`.
- Applied a consistent colour palette, typography, spacing, cards, buttons, tables and footer.
- Added desktop layout styling using CSS Grid and Flexbox.
- Added responsive breakpoints for tablets and mobile phones.
- Added a mobile-friendly navigation layout without JavaScript.
- Improved image sizing, captions and alternative text.
- Improved form layout and field presentation.
- Added consistent active navigation states.
- Added a responsive Johannesburg service-area map.
- Kept JavaScript out of Part 2 because interactive functionality and validation are planned for Part 3.

## How to run
Open `index.html` in a modern web browser. No server is required for the visual-design version.
